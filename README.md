# Lesson 7 영어 공부방

4학년 Lesson 7 *Writing Words and Sentences* (Is this your cap?) 시험 대비용 웹 앱.

- **① 단어 공부**: 시험지 20개 단어를 그림·뜻과 함께 듣기 / 천천히 / 철자 한 글자씩 듣기, 전체 듣기
- **② 문장 듣기**: 핵심 문장 듣기, 천천히, 한 단어씩, 3번 반복
- **③ 공책 문제**: 시험지 그대로 / 듣고 쓰기 / 그림 보고 쓰기 / 한글 보고 쓰기. 공책에 쓰고 정답 확인 후 스스로 O/X, 틀린 것만 다시 풀기
- **정답표**: 선생님용

`index.html` 하나만 열면 됩니다 (그림 포함). 소리는 브라우저 내장 음성(Web Speech)을 사용합니다.
